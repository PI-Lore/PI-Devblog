## About the game

Phoenix International is a dinosaur-themed roleplay game on Roblox, inspired by the Primal Carnage universe. Players take sides on a corporate research island: staff keep the facilities running, actors roleplay as dinosaurs on the Reserve, test subjects try to survive, and rogue groups threaten island operations.

## About this site

A static website. Each issue is an HTML page covering what the development team has built, fixed and is working on. Issues are published every [two weeks].

The game is in closed development. These updates are out-of-universe: they describe how the game is being made and are not tied to events inside the game's story.
